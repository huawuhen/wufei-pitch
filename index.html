STEP 05情感终局

CORE SETTING 01
流火
神秘能量物质 · Crimson Crystal

一种来自地底的红色晶体，外形如凝固的火焰。接触人体后会融入体内，通过吸收情绪获得能量，并放大宿主内心最强烈的执念。

CORE SETTING 02
臆想主
被流火寄生之人 · Phantasm Host

与流火融合的人类。他们的情绪和执念会影响周围现实，形成由自身潜意识主导的异常空间，是每个副本的核心源头。

CORE SETTING 03
臆想之地
执念形成的异常空间 · Rule Dungeon

由臆想主的欲望、恐惧或记忆创造的特殊空间。进入者必须按照空间设定的身份与规则行动，否则可能遭到惩罚甚至死亡。

CORE SETTING 04
锚点
情绪凝结的超凡道具 · Astral Anchor

流火吸收情绪后形成的特殊物品。拥有与其情绪特质匹配的人，可以使用锚点获得超自然能力，但也可能因排斥而死亡。
