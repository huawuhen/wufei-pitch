## 📖 项目简介与核心立项亮点

《代号：雾绯》（CODENAME: MIST & CRIMSON）是面向 18-35 岁（00后 Z 世代主导）女性向玩家的创新商业化提案。融合**微恐悬疑推理、无限流多元副本、双维动态数值养成与 9:16 竖屏短剧级视听**。

### 🌟 提案全景架构
1. **00 · 雾绯序幕 (Hero Opening)**：
   - 官方 Slogan：**“雾绯之间，唯爱永存”**；
   - 核心体量与定位数据指标矩阵（3-5人极简敏捷管线、8-12月周期、千万级首年流水目标）。
2. **01 · 世界观与主线 (Worldview & Heroine)**：
   - 19世纪伦敦架空维多利亚异象 × “臆想之地”多元副本；
   - 女主身份：**新兴贵女、警察（特别行动队专职处理臆想之地）**。
3. **02 · 核心设定与流火情绪实验室 (Core Settings & Flowing Fire)**：
   - 纯透明星盘铭文排布五大情绪图章（**愤怒·红 / 恐惧·黑 / 嫉妒·绿 / 喜悦·黄 / 哀伤·白**）；
   - *“流火会根据吸收的主要情绪改变颜色，并凝结出不同属性的锚点”*。
4. **03 · 宿命男主设定 (Characters Matrix)**：
   - **奥古斯特 · 卢西恩**（吸血鬼公爵 · 权势型）
   - **伊莱亚 · 艾伯特**（教廷圣子 · 禁欲型）
   - **闻九**（黑市情报官 · 轻浮型）
   - **维克多 · 尤里**（赏金猎人 · 直球忠犬）
5. **04 · 养成数值与实机演示 (Dungeon & Systems)**：
   - 双维核心数值看板：**「洞察值」（女主破局解谜）×「心契度」（男主情感羁绊）**；
   - **三联竖屏全景实机动图**：01 开场破雾、02 主界面交互、03 抽卡祈愿与数值；
   - 下方 9:16 核心副本展示：**其一《昨日尚未发生》**。
6. **05 · 画像与商业化 (Market & Monetization)**：
   - 00后女性核心用户画像星图、五步玩法与商业化闭环、三大差异化壁垒。
7. **06 · 界面与实机玩法参考 (UI Spec & Gameplay References)**：
   - 核心玩法动态 GIF 动效与交互灯箱（手部触碰、选择分支、弹珠对抗、分镜重组）。

## 💻 本地运行与预览

由于项目采用纯原生现代 Web 架构，无需安装 Node.js 复杂依赖，直接通过任意静态服务器即可运行：

```bash
# 方式 1：使用 Python 内置简易 HTTP 服务
python -m http.server 8080

# 方式 2：使用 Node.js serve
npx serve .

# 方式 3：或直接双击 index.html 体验
```

浏览器访问 `http://localhost:8080` 即可浏览完整提案。
